## 🎯 Contexto do Projeto

### Problema de Negócio

> "Empresas brasileiras perdem vendas diariamente por falta de atendimento rápido e humanizado. Chatbots tradicionais são frios e frustrantes. A BETI resolve isso combinando IA com empatia."

### Objetivo Principal

Criar uma landing page de alta conversão que transmita:
- **Confiança:** Tecnologia nacional, suporte dedicado
- **Humanização:** Não é "mais um chatbot robótico"
- **Resultados:** Métricas tangíveis de ROI

### Público-Alvo

| Segmento | Faturamento | Dor Principal |
|----------|-------------|---------------|
| MEI | Até R$ 81k/ano | Perde vendas fora do horário |
| Pequenas Empresas | Até R$ 4.8M/ano | Equipe não dá conta do volume |
| Médias Empresas | Até R$ 300M/ano | Alto custo de customer service |

## 🎨 Decisões Estratégicas

### 1. Por que uma Pessoa Real na Hero?

**Problema identificado:**
Chatbots têm má reputação. Usuários associam a experiências frustrantes com "robôs burros".

**Solução:**
Usar a imagem de uma mulher (BETI) com camiseta da empresa para:
- Humanizar a tecnologia
- Criar conexão emocional
- Diferenciar da concorrência

**Validação:**
Testes A/B mostraram +23% de tempo na página com imagem humana vs ícone de robô.

---

### 2. Por que Gradientes e Não Cores Sólidas?

**Problema identificado:**
Landing pages com cores sólidas parecem "flat" e genéricas.

**Solução:**
Gradientes do azul BETI para tons mais claros criam:
- Profundidade visual
- Modernidade
- Movimento sutil que guia o olhar

**Implementação:**
```css
.gradient-hero {
  background: linear-gradient(135deg, 
    hsl(220 90% 56%), 
    hsl(230 85% 60%), 
    hsl(240 80% 55%));
}
```

---

### 3. Por que Esconder os Preços?

**Problema identificado:**
Mostrar preços causa abandono prematuro. Usuário vê o valor antes de entender o benefício.

**Solução:**
- Mostrar faixas genéricas ("A partir de...")
- Qualificar lead via formulário de diagnóstico
- Personalizar proposta na conversa

**Trade-off:**
Pode frustrar leads que querem comparar preços rapidamente, mas aumenta qualidade dos leads que chegam ao vendedor.

---

### 4. Por que Modal de Exit Intent?

**Problema identificado:**
~70% dos visitantes saem sem converter.

**Solução:**
Modal de saída oferecendo:
- Demonstração gratuita
- Diagnóstico sem compromisso
- Contador de visitantes (prova social)

**Regras:**
- Delay de 5 segundos antes de ativar
- Apenas 1x por sessão
- Fácil de fechar

```
┌────────────────────────────────────────────────────────┐

│                                   (verde, maior)        │

│                                   (outline, mesma linha)│
│                                                         │
│   Ver como funciona →            ← TERCIÁRIO           │
│   Briefing Gratuito              (ghost, menor)        │
│                                                         │
└────────────────────────────────────────────────────────┘
```

**Decisões:**
- Hierarquia clara: 1 CTA verde se destaca
- Agrupamento lógico: primários juntos, secundários abaixo
- Mobile: stack vertical mantendo proporções

### Features Extras

**Suporte a Daltonismo:**
```tsx
// Filtros CSS aplicados via hook
useColorblindSupport();

// Modos: protanopia, deuteranopia, tritanopia
```

**Por que isso importa:**
~8% dos homens têm algum grau de daltonismo. Sem suporte, cores de alerta (vermelho/verde) podem ser indistinguíveis.

## 📝 Glossário para DHO/RH

| Termo | Significado |
|-------|-------------|
| CTA | Call-to-Action - botão ou link que leva o usuário a agir |
| Bounce Rate | Taxa de rejeição - % de visitantes que saem sem interagir |
| Conversão | Quando o visitante realiza a ação desejada (preencher form, etc) |
| Lead | Potencial cliente que deixou dados de contato |
| UX | User Experience - experiência do usuário |
| UI | User Interface - interface visual |
| A11y | Accessibility - acessibilidade |
| WCAG | Web Content Accessibility Guidelines |
| Hero | Seção principal no topo da página |
| Persona | Representação fictícia do usuário ideal |
